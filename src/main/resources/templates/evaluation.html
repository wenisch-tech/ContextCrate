Golden set

Questions with the documents that should be found and/or the answer that should be given. Running the set asks every question through the normal answer path and scores it against this ground truth, which gives a true Recall@K and the reference-answer check. Expected documents match as text inside the source address of a chunk (for example docs/oncall.md).

Ignore rules

Messages that match a rule (for example a monitoring tool asking “what is 1+1” as a health check) are hidden from the list below and left out of the averages and the report. They are only counted per rule. A question rule is checked before anything is sent to the judge, so ignored questions cost nothing; topic and tag rules apply once the topic is known. You can also press “Ignore” next to a question, topic or tag in the list. Removing a rule brings its messages back.
