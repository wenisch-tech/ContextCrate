Retrieval

How passages are found for searches and answers.

Proposition retrieval makes two answer-model calls per chunk before embedding and requires both providers. Changing the strategy rebuilds the index in the background.

Query transformation

Reshapes the question before retrieval so answers find better passages. The original question is still what the model answers.

Selected strategies run in this order: rewriting → step-back → sub-queries, each building on the previous result. Every active strategy adds one answer-model call before retrieval. Requires an enabled answer model.
